## Notes for Vercel Migration

To migrate subdomains to Vercel, you'll need to add new A records:

- `en` → Vercel IP (e.g., 76.76.19.61)
- `hu` → Vercel IP (e.g., 76.76.19.61)
- `de` → Vercel IP (e.g., 76.76.19.61)

This will create `en.flair-plastic.hu`, `hu.flair-plastic.hu`, and `de.flair-plastic.hu` pointing to Vercel while keeping your main domain services on traditional hosting.
